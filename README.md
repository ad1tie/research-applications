# Research Applications in C

A collection of utility tools and systems programming implementations in C.

## Included Modules

- **Lyrics Syncer (`lyricssyncer.c`)**: Synchronizes and parses `.lrc` lyric files (`TSWTNYtest.lrc`) with audio timestamps.
- **Custom Memory Allocator (`memory_allocator.c`)**: A low-level dynamic memory allocation and block management implementation.
- **Progress Tracker (`progresstracker.c`)**: Utility to monitor and report task or execution milestones.
